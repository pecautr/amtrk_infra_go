🗺️ City Map Poster Generator

Create aesthetic black and white street and rail maps for printing

📦 Setup Required

This application requires mapping libraries to function. To use the full-featured version:

  • Option 1 (CDN - Recommended for web deployment): Edit index-full.html to use Leaflet from CDN (works when deployed to a web server with internet access)
  • Option 2 (Local - For offline use): Download Leaflet.js library manually and place in lib/leaflet/ directory:
    • Download from leafletjs.com
    • Extract to map-poster-generator/lib/leaflet/
    • Then use index-full.html
  • Option 3 (Quick demo): View the screenshot below or open the application in a browser with internet access

📖 For full documentation, see README.md

Customize Your Map

Requires Leaflet.js and internet connection

ℹ️ How to Use
  1. Search for your city or drag the map to your desired location
  2. Zoom in/out to frame your area
  3. Customize colors, style, and features
  4. Adjust poster size and border
  5. Export or print your custom map poster

Note: This is a demo page. See setup instructions above to enable full functionality.
